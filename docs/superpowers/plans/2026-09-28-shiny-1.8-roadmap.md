# Shiny 1.8 Roadmap (1.13.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Use the Shiny for Python capabilities the package still ignores, in the order `docs/2026-09-28-shiny-1.8-improvements.md` recommends: server→client RPC with replies, dark-mode following, bookmarking, HTTP transport for large payloads, official test helpers, test-mode snapshots and module-scope hygiene — released as 1.13.0.

**Architecture:** `MapWidget` (Python) talks to `resources/deckgl-init.js` through Shiny custom messages; results come back as Shiny inputs. This plan adds one *reply channel* (the client answers a `deck_request` through `Shiny.shinyapp.makeRequest()` → `session.set_message_handler()`), a client-side dark-mode observer, per-session bookmark hooks, an alternative payload transport (`session.dynamic_route()` + `fetch`), and test tooling. All per-session state keeps using `_remember/_recall`.

**Tech Stack:** Python ≥ 3.10, Shiny 1.6.3 runtime floor (features that need more check the installed version and raise/skip), deck.gl 9.4.0, MapLibre 6.11.2, pytest, Node harness (`tests/_js_harness.py`), Playwright (browser modules run one file at a time; new apps take ports 18779+).

**Spec:** `docs/2026-09-28-shiny-1.8-improvements.md`.

## Global Constraints

- Runtime floor stays `shiny>=1.6.3`. Bookmarking requires 1.6.4 (CWE-22 fix): check `importlib.metadata.version("shiny")` and raise `RuntimeError` with the reason. `set_message_handler`, `dynamic_route`, `extended_task` exist in 1.6.3.
- **The session loop awaits the reactive flush inline** (`shiny/session/_session.py` `_run`), so a coroutine that awaits a browser reply *inside a reactive effect* deadlocks: the reply message is read only after the flush ends. `MapWidget.rpc()` (Task 1) therefore raises immediately when called from a non-denial reactive context and documents `reactive.extended_task` as the call site (`ExtendedTask` runs the coroutine in its own `asyncio.Task` under a `DenialContext`).
- Every new Shiny input the runtime emits gets a `MapWidget.<name>_input_id` property; every new message handler in the runtime is a **named** function passed to `addDeferrable` (so the Node harness can extract it).
- Existing input-based flows (`_query_result`, `_export_result`, `_has_image`) stay unchanged; RPC methods are additions.
- Run unit tests as `micromamba run -n shiny python -c "import pytest,os,sys; rc=pytest.main([...]); sys.stdout.flush(); os._exit(0)"`; browser modules one file at a time; `-m "not browser"` for the unit suite.

## Review Focus

1. **RPC awaited inside a plain effect.** Must raise `RuntimeError` mentioning `extended_task` before sending anything (Task 1 test).
2. **RPC reply for an unknown/expired request id** (timeout already fired, or a stale tab). Must be ignored without error (Task 1 test).
3. **Dark-mode swap while native layers exist.** The swap goes through the same style path as `set_style`, so the "re-add native layers" warning and `resetNativeLayers` apply; the input `<id>_dark_mode` reports the style in force so the server can re-add (Task 2 test).
4. **Bookmark restore with no map input in the state** (first visit, or the widget was added later). `on_restored` must be a no-op (Task 3 test).
5. **A `partial_update` arriving while an HTTP `deck_update` is still being fetched.** Layer-dependent handlers wait for the pending fetch so order is preserved (Task 4 Node test).

class _RpcSession(_FakeSession):
    """Answers every deck_request through the handler the widget registered."""

    def __init__(self, answers=None, *, reply=True):
        super().__init__()
        self.handlers: dict[str, object] = {}
        self.answers = answers or {}
        self.reply = reply

    def set_message_handler(self, name, handler):
        self.handlers[name] = handler
        return name

            if isinstance(ans, Exception):
                await fn(payload["requestId"], None, str(ans))
            else:
                await fn(payload["requestId"], ans, None)

```python
    # -- RPC: ask the browser and await its answer ---------------------------
    # The session loop awaits the reactive flush inline, so awaiting a reply
    # from inside a plain reactive effect deadlocks (the reply is read only
    # after the flush). reactive.extended_task runs its coroutine in its own
    # asyncio task under a DenialContext, which is the supported call site.

    def _rpc_state(self, session) -> dict:
        st = self._recall(session, "rpc_state")
        if st is None:
            st = {"pending": {}, "seq": 0, "handler": False}
            self._remember(session, "rpc_state", st)
        return st

    @property
    def rpc_reply_handler_name(self) -> str:
        return f"{self.id}_rpc_reply"

    async def rpc(self, session, method, params=None, *, timeout=10.0):
        _refuse_inside_flush()
        st = self._rpc_state(session)
        if not st["handler"]:
            def _on_reply(request_id, result=None, error=None):
                fut = st["pending"].pop(request_id, None)
                if fut is None or fut.done():
                    return None                    # stale or timed-out request
                if error:
                    fut.set_exception(RuntimeError(str(error)))
                else:
                    fut.set_result(result)
                return None
            session.set_message_handler(self.rpc_reply_handler_name, _on_reply)
            st["handler"] = True
        st["seq"] += 1
        request_id = f"{self._bare_id}-{st['seq']}"
        fut = asyncio.get_running_loop().create_future()
        st["pending"][request_id] = fut
        await session.send_custom_message("deck_request", json_safe({
            "id": self.id, "requestId": request_id, "method": method, "params": params or {},
        }))
        try:
            return await asyncio.wait_for(fut, timeout)
        except asyncio.TimeoutError:
            st["pending"].pop(request_id, None)
            raise TimeoutError(
                f"{method}: no reply from the browser within {timeout}s. rpc() must be awaited "
                "from a reactive.extended_task (or outside the reactive flush); see MapWidget.rpc."
            ) from None
```
with module-level
```python
def _refuse_inside_flush() -> None:
    from shiny import reactive
    try:
        ctx = reactive.get_current_context()
    except RuntimeError:
        return                                   # no reactive context: fine
    try:
        from shiny.reactive._extended_task import DenialContext
    except ImportError:                          # pragma: no cover
        DenialContext = ()                        # type: ignore[assignment]
    if isinstance(ctx, DenialContext):
        return                                   # inside an extended_task: fine
    raise RuntimeError(
        "MapWidget.rpc() cannot be awaited inside a reactive effect/calc/render: the session "
        "loop waits for the flush, so the browser's reply could never be read (deadlock). "
        "Call it from a reactive.extended_task and read task.result()."
    )
```
and the four typed wrappers (`get_image` decodes the `dataUrl` with `base64.b64decode(data_url.split(',', 1)[1])`; `get_features` maps `filter_expr`→`filter`, `lnglat`, `point`, `bounds`, `layers`).

Note `reactive.isolate()` also creates a plain `Context`, so the test's `with reactive.isolate()` exercises the refusal; the `set_message_handler` handler itself runs under `isolate()` on Shiny's side but does not call `rpc`.

- [ ] **Step 4: Implement (JS)** — before the `deck_query_features` handler:

```js
  // Server -> client requests with a reply: Python's MapWidget.rpc() sends
  // deck_request {id, requestId, method, params}; the method's value (or the
  // promise it returns) goes back through Shiny.shinyapp.makeRequest() to the
  // handler set_message_handler() registered as "<id>_rpc_reply".
  var RPC_METHODS = {
    getViewState: function (instance) {
      var map = instance.map, c = map.getCenter(), b = map.getBounds();
      return { longitude: c.lng, latitude: c.lat, zoom: map.getZoom(), pitch: map.getPitch(),
               bearing: map.getBearing(),
               bounds: { sw: [b.getWest(), b.getSouth()], ne: [b.getEast(), b.getNorth()] } };
    },
    queryFeatures: function (instance, params) {
      return new Promise(function (resolve) {
        whenStyleReady(instance.map, function () {
          var opts = {};
          if (params.layers) opts.layers = params.layers;
          if (params.filter) opts.filter = params.filter;
          var geom = params.point || params.bounds;
          if (params.lnglat) { var p = instance.map.project(params.lnglat); geom = [p.x, p.y]; }
          var feats = geom ? instance.map.queryRenderedFeatures(geom, opts) : instance.map.queryRenderedFeatures(opts);
          resolve(feats.map(simplifyFeature));
        });
      });
    },
    exportImage: function (instance, params) {
      return new Promise(function (resolve) { captureMapImage(instance, params, resolve); });
    },
    hasImage: function (instance, params) { return !!instance.map.hasImage(params.imageId); },
  };

  function rpcReply(payload, result, error) {
    if (!(window.Shiny && Shiny.shinyapp && Shiny.shinyapp.makeRequest)) {
      console.warn('[shiny_deckgl] deck_request: Shiny.shinyapp.makeRequest unavailable'); return;
    }
    Shiny.shinyapp.makeRequest(payload.id + '_rpc_reply', [payload.requestId, result, error],
      function () {}, function (err) { console.warn('[shiny_deckgl] rpc reply failed:', err); });
  }

  function handleDeckRequest(payload) {
    if (!payload || !payload.id || !payload.requestId) return;
    var instance = mapInstances[payload.id];
    var fn = RPC_METHODS[payload.method];
    if (!instance) return rpcReply(payload, null, 'no such map: ' + payload.id);
    if (!fn) return rpcReply(payload, null, 'unknown rpc method: ' + payload.method);
    var out;
    try { out = fn(instance, payload.params || {}); }
    catch (e) { return rpcReply(payload, null, String(e && e.message || e)); }
    Promise.resolve(out).then(
      function (v) { rpcReply(payload, v === undefined ? null : v, null); },
      function (e) { rpcReply(payload, null, String(e && e.message || e)); });
  }
  addDeferrable("deck_request", handleDeckRequest);
```
